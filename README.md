# codeshell releases

Installers for codeshell, a Windows terminal workspace for Claude Code, Codex and shells.

Download `codeshell_<version>_x64-setup.exe` from the [latest release](https://github.com/nks1990/codeshell-releases/releases/latest) and run it. It installs for the current user, no admin rights needed.

Installed copies update themselves: when a new release is published, codeshell shows a dialog and installs it.

This repository holds only release files. The source code is private.
